5. Опишите основные плюсы и минусы pull и push систем мониторинга.

## Ответ:

Pull 
Плюсы:
  - легко обнаруживать недоступные узлы (нет метрики — проблема);
  - единая точка конфигурации сбора;
  - встроенная проверка валидности метрик через service discovery.
Минусы:
  - нужно открывать порты на наблюдаемых системах;
  - труднее собирать метрики с краткоживущих джоб;
  - медленнее реагирует на частые изменения IP/портов.

Push 
Плюсы:
  - проще собирать метрики с временных серверов и контейнеров;
  - не требует открытия входящих портов (агенты сами подключаются);
  - удобен для batch-процессов (можно отправить метрику только по завершению)
Минусы:
  - сложнее определить, что узел молчит из-за поломки, а не потому, что нечего отправить;
  - нужна буферизация (риск потери метрик при перегрузке);
  - выше риск перегрузки системы мониторинга при flash-трафике.

6. Какие из ниже перечисленных систем относятся к push модели, а какие к pull? А может есть гибридные?

    - Prometheus 
    - TICK
    - Zabbix
    - VictoriaMetrics
    - Nagios


## Ответ:

    Prometheus - pull, сервер сам активно забирает метрики с настроенных целей;
    TICK - (Telegraf + InfluxDB) push, агент Telegraf отправляет метрики в базу InfluxDB;
    Zabbix - гибридная, поддерживает оба режима: активные и пассивные проверки агентов;
    VictoriaMetrics - гибридная, изначально pull как совместимая с Prometheus, но также умеет принимать данные через push;
    Nagios - гибридная, активные проверки плагинов = pull, пассивные проверки от внешних источников = push.

9. Изучите список telegraf inputs. Добавьте в конфигурацию telegraf следующий плагин - docker:

```
[[inputs.docker]]
  endpoint = "unix:///var/run/docker.sock"
```

Дополнительно вам может потребоваться донастройка контейнера telegraf в docker-compose.yml дополнительного volume и режима privileged:

```
    telegraf:
    image: telegraf:1.4.0
    privileged: true
    volumes:
      - ./etc/telegraf.conf:/etc/telegraf/telegraf.conf:Z
      - /var/run/docker.sock:/var/run/docker.sock:Z
    links:
      - influxdb
    ports:
      - "8092:8092/udp"
      - "8094:8094"
      - "8125:8125/udp"
```

После настройке перезапустите telegraf, обновите веб интерфейс и приведите скриншотом список measurments в веб-интерфейсе базы telegraf.autogen . Там должны появиться метрики, связанные с docker.
